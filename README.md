A Julia package for generating Gaussian Markov random fields with Matérn covariance functions on [Oceananigans](https://github.com/CliMA/Oceananigans.jl) grids using the _stochastic partial differential equation_ (SPDE) approach of [Lindgren, Rue and Lindström (2011)](https://doi.org/10.1111/j.1467-9868.2011.00777.x).

For more details about the package and how to use it, [head to our documentation site](https://aria-verify.github.io/RandomFields.jl).
