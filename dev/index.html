RandomFields.RandomFieldGenerator — Type
struct RandomFieldGenerator{G, L, T, F, H, S}

Precomputed quantities and buffer storage for generating Gaussian random fields

Fields

  • grid::Any: Oceananigans grid fields will be generated on

  • location::Any: Staggered grid location tuple fields will be generated on

  • n_inverse_apply::Int64: Number of times inverse of modified Helmholtz linear operator is applied to generate field

  • require_half_order::Bool: Whether the inverse half-order modified Helmholtz linear operator needs to be applied to generate field

  • weights::Tuple{Vararg{T}} where T: Length-scale based weights for second derivative terms in modified Helmholtz operator

  • field_buffer_a::Any: Field buffer used to store intermediate quantities during computation

  • field_buffer_b::Any: Field buffer used to store intermediate quantities during computation

  • white_noise_scale::Any: Field used to store precomputed per-cell scale factors for white noise generation

  • modified_helmholtz_operator::Any: Linear operator corresponding to modified Helmholtz equation for the parameters of interest

  • solver::Any: Solver for linear system in modified Helmholtz operator

  • n_sqrt_quadrature_points::Int64: Number of quadrature points to use in integral approximation to square root of linear operator

RandomFields.RandomFieldGenerator — Method
RandomFieldGenerator(
    field,
    parameters;
    reltol,
    maxiter,
    n_sqrt_quadrature_points
)

Construct a random field generator for template field with covariance parameters parameters.

The linear systems are solved using a conjugate gradient solver with relative tolerance reltol and maximum number of iterations maxiter and the half-order (square-root) linear operator inverse is approximated using quadrature of an integral representation with n_sqrt_quadrature_points quadrature points if relevant.

RandomFields.generate! — Method
generate!(field, generator, noise)

Overwrite field with an (approximate) draw from a mean-zero Gaussian random field with Matérn covariance, via the SPDE representation (1 - Σᵢλᵢ²∂ᵢ²)^(ν+d/2) f = τ w where λᵢ are per-dimension length scale parameters, ν a smoothness index, d the spatial dimension, f the field being solved for, τ an output scaling parameter and w a spatial white noise process. generator should be a RandomFieldGenerator built once via RandomFieldGenerator(field, parameters) and reusable across calls, with parameters an instance of IsotropicMatern or AnisotropicMatern and noise is an array of standard normal variates with size(noise) == size(field).
